On-device translation for the web

Documentation · Updated recently

Chrome provides built-in AI APIs that run locally, so users can translate content without sending text to remote servers.

The Translator API enables fast language translation directly in the browser. Select any sentence on a page and view an instant translation in context, while keeping your data on your device.

Developers can combine translation with language detection and prompting to build private, responsive experiences.
