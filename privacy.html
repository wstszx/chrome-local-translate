本地翻译 · 隐私政策

最后更新：2026年11月

1. 我们收集什么信息

本浏览器扩展程序（"扩展"）致力于保护您的隐私。我们不收集、存储或传输任何可识别个人身份的信息。

2. 使用数据（不收集）

本扩展不收集、不传输、不存储任何可识别个人身份的信息，也不做任何遥测或统计上报。代码中没有向外部服务器发送数据的机制（无 fetch / WebSocket / Beacon 等网络调用）。扩展版本号、引擎类型、语言对配置等仅为本地运行状态，存储在您本机的浏览器内，不上传。

3. 翻译处理

所有翻译文本都在您的设备本地处理，绝不发送到外部服务器。Chrome 内置的 Translator API 和 Gemini Nano 模型均在本地运行，文本不出本机。

4. 第三方服务

扩展程序使用以下本地服务，所有处理均在您的设备上完成：

  • Chrome Translator API（内置模型）
  • Gemini Nano（Chrome 设备内置模型，需 ≥ Chrome 138）

这些服务不收集或存储您的翻译内容。

5. Cookie & 存储

扩展程序使用 Chrome storage.local 存储用户设置（语言偏好、术语表、配置等）。这些数据仅在您的浏览器中本地存储，不会共享给第三方。

6. 您的权利

您可以随时：

  • 在扩展设置中清除所有缓存和配置
  • 禁用或卸载扩展程序
  • 在 chrome://extensions 中管理权限
