Local Translate · Privacy Policy / 隐私政策

Last updated / 最后更新：2026-11-18

Applies to the Chrome extension “Local Translate – On-Device AI” (also distributed in some locales as “本地翻译”). This page is provided for users and for Chrome Web Store disclosure; the hosted copy used in the store listing may be published at https://chrome-local-translate-privacy.wstszx.workers.dev/privacy.html.

English

1. Data collection and transmission

We do not collect, sell, or transmit your personal information to the developer or to third parties. The extension does not include analytics, telemetry, advertising SDKs, or network requests from extension code to external servers (no fetch, XHR, WebSocket, or beacon APIs for data upload).

2. On-device processing

Translation, rewriting, and related language features run locally on your device using Chrome’s built-in on-device AI capabilities (such as the Translator API and Prompt API / Gemini Nano, when available). Page content, selected text, and input text are processed locally for these features and are not uploaded by this extension to external servers.

3. Local storage on your device

To provide its functionality, the extension stores data locally in your browser (for example via chrome.storage.local and/or chrome.storage.sync, depending on the feature and your settings). This may include settings, site-specific preferences/rules, translation cache, and translation history. This data stays on your device/browser profile unless your browser syncs Chrome storage according to your Google/Chrome settings. You can clear extension data from the extension UI where available or remove it by uninstalling the extension.

4. Permissions and purpose

  • storage: save settings, preferences, cache, and history locally.
  • contextMenus: provide right-click translation actions.
  • sidePanel: open the extension side panel UI.
  • offscreen: host local inference/processing required by Chrome extension architecture.
  • activeTab / scripting / host permissions (<all_urls>): inject translation UI and scripts into pages you visit (including frames such as iframes/about:blank where needed) to enable selection translation, full-page translation, and input rewriting. This access is used to provide the extension’s single purpose and not to exfiltrate page content.

5. Third parties

The extension does not share your data with third parties. It relies on on-device capabilities provided by the Chrome browser/runtime.

6. Contact

For privacy questions, contact: mywstszx@gmail.com or open an issue at GitHub Issues.

中文

1. 数据收集与传输

我们不会向开发者或任何第三方收集、出售或传输您的个人信息。扩展不包含分析/遥测/广告 SDK，扩展代码也不会向外部服务器发起用于上传数据的网络请求（无 fetch、XHR、WebSocket、Beacon 等）。

2. 设备端本地处理

翻译、转写及相关语言功能在您的设备本地运行，使用 Chrome 内置的设备端 AI 能力（如可用的 Translator API、Prompt API / Gemini Nano）。为实现这些功能所处理的页面内容、选中文本和输入文本均在本地处理，本扩展不会将其上传到外部服务器。

3. 本机本地存储

为提供功能，扩展会在您的浏览器中本地存储数据（例如通过 chrome.storage.local 和/或 chrome.storage.sync，具体取决于功能与设置）。这些数据可能包括设置、站点偏好/规则、译文缓存和翻译历史。除非您的浏览器根据自身设置同步 Chrome 存储，否则数据仅保留在本机/浏览器配置文件中。您可以在扩展界面中清理相关数据（如可用），或通过卸载扩展移除本地数据。

4. 权限与用途

  • storage：在本地保存设置、偏好、缓存和历史记录。
  • contextMenus：提供右键翻译菜单。
  • sidePanel：打开扩展侧边栏界面。
  • offscreen：承载 Chrome 扩展架构所需的本地推理/处理宿主。
  • activeTab / scripting / host 权限（<all_urls>）：在您访问的网页中注入翻译 UI 与脚本（在需要时包括 iframe / about:blank 等框架），以实现划词翻译、整页翻译和输入框转写。此访问仅用于提供扩展的单一用途，不用于外传页面内容。

5. 第三方

扩展不会与第三方共享您的数据。扩展依赖 Chrome 浏览器/运行时提供的设备端能力。

6. 联系方式

如有隐私相关问题，请联系：mywstszx@gmail.com，或在 GitHub Issues 提交问题。
